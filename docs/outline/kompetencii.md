# Компетенции

Ожидание ниже — для L5. Имена инструментов в нём — текущая реализация. Годится любой механизм, пока выполняются результаты из зоны ответственности.

База, без которой навыки L5 не применить: разработка сервисов и интерфейсов, распределённые системы и повторы, Linux, сети, Kubernetes и инфраструктура как код, цикл агента, MCP и A2A, типовые риски агентных систем на уровне, достаточном чтобы реализовать требование Security.

| Группа | Компетенция | Ожидание L5 |
| --- | --- | --- |
| Среда | Изоляция сессии | Проектирует профиль и изоляцию так, что побочный эффект одной сессии не выходит в другую. Профиль фиксируется на старте и меняется только новым запуском |
| Среда | Правило до действия | Ставит проверку до выполнения, после него и при остановке. По умолчанию запрещено всё, что явно не разрешено. Если проверка недоступна, действие не выполняется |
| Среда | Обмен между агентами | Держит официальный канал единственным способом передать этап. Скрытый обмен заводит как инцидент и убирает причину, по которой он был удобнее |
| Среда | Восстановление | Проектирует контрольную точку и продолжение длинной работы. Отличает «действие не выполнено» от «ответ потерян, а эффект уже мог случиться» и не повторяет внешнее действие вслепую |
| Среда | Объяснимость | Связывает шаг с субъектом, правами, правилом и его версией. Журнал и слой «почему разрешено» только дописываются |
| Платформа | Распределённые системы | Проектирует поведение при частичном отказе, потере сообщения и повторном запросе. Один и тот же внешний эффект не возникает дважды |
| Платформа | Инфраструктура | Ведёт кластер, сеть, хранилища, секреты, балансировщики и сертификаты как часть платформы. Новые узлы получают те же ограничения, что и старые |
| Платформа | Нагрузка и стоимость | Считает стоимость сессии, расход токенов и отношение цены работы модели к подтверждённому результату. Лимит и автоматический останов — правило платформы |
| Платформа | Выпуск без обрыва | Выпускает объекты среды одним конвейером, с ограниченной долей и откатом. Новая версия не прерывает идущие длительные задачи |
| Платформа | Шлюз к моделям | Переключает модель настройкой. Недоступность одного поставщика не останавливает агентов |
| Границы | Чужое не забирает | Не пишет текст политик, не задаёт порог качества, не формулирует продуктовую гипотезу и не ведёт жизненный цикл отдельного агента. Свой результат — механизм, который исполняет чужое правило |
| Границы | Язык соседа | Слышит запрос Product Engineer, Security, Architect, Eval и AgentOps и отвечает изменением среды. Если сделать иначе нельзя, называет причину и альтернативу |
| Результат | Платформа как сервис | Доводит неструктурированную задачу до работающей возможности, которой пользуются несколько команд без личного участия «человека с платформы». Официальный путь проще обхода |
| Результат | Измеримый эффект | Показывает эффект изменением среды: время восстановления сессии, время выката, доля ручных операций, останов перерасхода. Проверка нужна ради этого результата |
| Люди | Золотой путь | Учит команды запускать работу через платформу, читать отказ среды и снижать риск маленькими изменениями. Считает полную стоимость решения, включая токены |
| Люди | Развитие инженеров среды | Проводит интервью в зоне среды и планирует развитие инженеров младшего уровня так, чтобы гарантия жила без автора |
